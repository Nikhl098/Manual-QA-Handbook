# Web App Testing Checklist

## Functional
- [ ] All links and buttons work
- [ ] Forms accept valid input and reject invalid input
- [ ] Mandatory fields are enforced
- [ ] Error and success messages are clear
- [ ] Search, filter and sort work
- [ ] Pagination works
- [ ] Login, logout and session timeout work
- [ ] File upload and download work

## UI
- [ ] Layout is aligned, no overlapping or cut text
- [ ] Fonts, colors and spacing are consistent
- [ ] Images load and have alt text
- [ ] Hover, focus and disabled states are visible

## Compatibility
- [ ] Chrome, Firefox, Edge, Safari
- [ ] Windows, macOS, Android, iOS
- [ ] Mobile, tablet and desktop widths

## Performance
- [ ] Pages load in reasonable time
- [ ] No long freezes on large data

## Security basics
- [ ] Password is masked
- [ ] Pages behind login cannot be opened by URL when logged out
- [ ] Input fields handle special characters and script tags safely
- [ ] HTTPS is used

## Usability and accessibility
- [ ] Keyboard navigation works
- [ ] Labels are clear
- [ ] Back button and refresh behave sensibly
