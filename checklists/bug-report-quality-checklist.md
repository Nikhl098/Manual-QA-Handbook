# Bug Report Quality Checklist

Before you click Submit:

- [ ] Searched for duplicates
- [ ] Title is short and specific
- [ ] Steps are numbered and anyone can follow them
- [ ] Expected and actual results are both written
- [ ] Build version and environment included
- [ ] Screenshot or video attached
- [ ] Severity and priority set sensibly
- [ ] Reproduced at least twice, or marked as intermittent
