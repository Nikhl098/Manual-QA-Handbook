# Login Form Checklist

- [ ] Valid username and password logs in
- [ ] Wrong password shows an error
- [ ] Unknown username shows an error
- [ ] Empty username, empty password, both empty
- [ ] Leading and trailing spaces
- [ ] Username case sensitivity as per requirement
- [ ] Password is masked, show/hide toggle works
- [ ] Copy from the password field is blocked if required
- [ ] Enter key submits the form
- [ ] Account locks after the configured number of failed attempts
- [ ] Forgot password link works
- [ ] Remember me works
- [ ] Session ends on logout and Back does not reopen the account
- [ ] Session timeout after inactivity
- [ ] SQL injection and script text in fields is handled safely
- [ ] Works on supported browsers and mobile
