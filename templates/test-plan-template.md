# Test Plan Template

## 1. Introduction
Short description of the product and the purpose of this plan.

## 2. Scope
### In scope
Features and modules to be tested.
### Out of scope
Features that will not be tested, with reasons.

## 3. Test Approach
Types of testing (functional, regression, smoke, API, compatibility), techniques, and whether manual or automated.

## 4. Test Environment
Browsers, devices, operating systems, servers, test accounts, test data.

## 5. Entry Criteria
- Requirements are approved
- Build is deployed to the test environment
- Smoke test passed

## 6. Exit Criteria
- All planned test cases executed
- No open Critical or High defects
- Agreed pass rate reached
