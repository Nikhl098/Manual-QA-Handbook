# Bug Report Template

| Field | Value |
|---|---|
| Bug ID | BUG-001 |
| Title | Short and specific: what is wrong and where |
| Reported By / Date | (name, date) |
| Module | Checkout |
| Build / Version | 1.4.2 |
| Environment | Chrome 120, Windows 11, QA server |
| Severity | Critical / High / Medium / Low |
| Priority | High / Medium / Low |
| Status | New |
| Assigned To | (developer) |
| Reproducible | Always / Sometimes / Once |

## Steps to reproduce

1. Open ...
2. Click ...
3. Enter ...

## Expected result

What should happen.

## Actual result

What happened instead.

## Evidence

Screenshot, screen recording, console log or network response.

## Notes

Workaround, frequency, related bugs.

## Good title examples

- Checkout: Place Order button does nothing when a coupon is applied
- Login: Error message missing when password field is empty
- Profile: Phone number accepts letters

## Bad title examples

- Not working
- Bug on page
- Please check
