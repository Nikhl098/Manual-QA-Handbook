# Contributing

Thanks for helping make this handbook better.

## Ways to help
- Fix a wrong or unclear answer
- Add a new interview question with a short, correct answer
- Add a checklist or template that testers actually use
- Fix typos and broken links

## How to contribute
1. Fork the repository
2. Create a branch: `git checkout -b add-question-xyz`
3. Make your change
4. Commit with a clear message
5. Open a pull request and say what you changed and why

## Rules
- Keep answers correct, short and in simple English
- Do not copy text from books, paid courses or other sites
- One topic per pull request
- Use the existing question format: `### Qn. Question` followed by the answer

## Reporting problems
Open an issue using the templates provided.
