# 09. More Concepts

[Back to README](../README.md)

20 questions.

### Q1. What is a test harness?

A set of tools, drivers, stubs and data used to run tests automatically and collect results.

### Q2. What is the difference between test case and test data?

A test case defines what to do and what to expect. Test data is the input values used when running it.

### Q3. What is mutation testing?

Making small changes to the code on purpose to check whether the existing tests catch them, which measures test quality.

### Q4. What is a requirement review?

Examining requirements for clarity, completeness and testability before development starts.

### Q5. What is cyclomatic complexity?

A measure of the number of independent paths through code. Higher values mean more complex code that needs more tests.

### Q6. What is the difference between a bug and an enhancement?

A bug is behavior that violates the requirement. An enhancement is a request for new or better behavior that was never required.

### Q7. What is concurrency testing?

Testing how the system behaves when multiple users or processes act on the same data at the same time.

### Q8. What is a test matrix?

A table that lists test conditions against items such as browsers, devices or roles, to track coverage.

### Q9. What is configuration management?

Controlling and tracking versions of code, documents and environments so changes are traceable.

### Q10. What is a baseline?

An approved version of a document or product that serves as a reference for later changes.

### Q11. What is a prototype?

An early sample or model of the product used to gather feedback before building the full system.

### Q12. What is a proof of concept?

A small implementation that shows an idea is technically feasible.

### Q13. What is data-driven testing?

Running the same test logic with many sets of input data, usually read from a file or table.

### Q14. What is keyword-driven testing?

Writing tests using keywords such as "login" or "click" that map to actions, so non-programmers can design tests.

### Q15. What is a hybrid testing framework?

A framework that combines two or more approaches, such as data-driven and keyword-driven.

### Q16. What is headless browser testing?

Running browser tests without a visible window, which is faster and good for CI servers.

### Q17. What is a test pyramid?

A model that suggests many unit tests, fewer integration tests and the fewest UI end-to-end tests.

### Q18. What is service virtualization?

Simulating the behavior of dependent systems that are unavailable so testing can continue.

### Q19. What is usability heuristics evaluation?

An expert review of an interface against recognized usability principles, such as consistency and clear feedback.

### Q20. What is test automation ROI?

The return compared to cost: time saved by running tests automatically versus the cost of building and maintaining them.
