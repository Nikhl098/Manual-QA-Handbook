# Manual QA Learning Roadmap

A simple order to learn in. Move on when you can explain each step in your own words.

1. **Basics**: what testing is, QA vs QC, principles of testing. See [fundamentals](../interview-questions/01-fundamentals.md).
2. **SDLC and STLC**, Agile and Scrum. See [SDLC and STLC](../interview-questions/02-sdlc-stlc.md).
3. **Test design**: write test cases using equivalence partitioning and boundary values. See the [cheat sheet](../cheatsheets/test-design-techniques.md).
4. **Bug reporting**: practice with the [bug template](../templates/bug-report-template.md).
5. **Jira basics**: create a free account, make a project, log issues.
6. **Practice on demo sites**: pick a public demo shop or login page, write 20 test cases, and report real bugs you find.
7. **API testing**: learn Postman and the [HTTP status codes](../cheatsheets/http-status-codes.md).
8. **SQL basics**: use the [SQL cheat sheet](../cheatsheets/sql-for-testers.md).
9. **Build a portfolio**: put your test plan, test cases and bug reports in a public GitHub repo.
10. **Interview prep**: go through all [interview questions](../interview-questions/README.md) and say answers out loud.
11. **Next step**: learn basic automation (Java or Python, Selenium).
