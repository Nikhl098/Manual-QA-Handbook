# HTTP Status Codes for Testers

| Code | Name | Meaning |
|---|---|---|
| 200 | OK | Request succeeded |
| 201 | Created | New resource created |
| 204 | No Content | Success, nothing to return |
| 301 | Moved Permanently | URL has a new permanent address |
| 302 | Found | Temporary redirect |
| 304 | Not Modified | Use cached copy |
| 400 | Bad Request | Invalid request |
| 401 | Unauthorized | Not authenticated |
| 403 | Forbidden | Authenticated but not allowed |
| 404 | Not Found | Resource does not exist |
| 405 | Method Not Allowed | Wrong HTTP method |
| 409 | Conflict | Conflicts with current state, such as a duplicate |
| 422 | Unprocessable Entity | Valid format but data fails validation |
| 429 | Too Many Requests | Rate limit hit |
| 500 | Internal Server Error | Server failed |
| 502 | Bad Gateway | Upstream server gave a bad response |
| 503 | Service Unavailable | Server down or overloaded |
| 504 | Gateway Timeout | Upstream server timed out |
