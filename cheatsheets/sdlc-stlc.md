# SDLC and STLC Cheat Sheet

## SDLC phases
Requirements, Analysis, Design, Development, Testing, Deployment, Maintenance.

## STLC phases
| Phase | Main activity | Output |
|---|---|---|
| Requirement analysis | Study requirements, find gaps | Questions, testable items |
| Test planning | Scope, approach, estimates | Test plan |
| Test case design | Write cases and data | Test cases, RTM |
| Environment setup | Prepare build and servers | Ready environment, smoke result |
| Test execution | Run tests, log bugs | Results, defect reports |
| Test closure | Analyze and report | Test summary report |

## Models at a glance
| Model | Idea | Good for |
|---|---|---|
| Waterfall | Linear phases | Fixed, clear requirements |
| V-Model | Each phase has a matching test phase | Strict, well-documented projects |
| Iterative | Build in repeated cycles | Growing products |
| Agile / Scrum | Short sprints, feedback | Changing requirements |
| Kanban | Visual flow, limit WIP | Continuous support work |
