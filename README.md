## Who is this for?

- Freshers preparing for a manual testing or QA interview
- Career changers learning software testing
- Working testers who want ready-to-use templates and checklists

Everything here is free to use, copy and share under the MIT license.

## How to use this repo

1. Click **Star** so you can find it later.
2. Clone it: `git clone <this-repo-url>` or use **Code > Download ZIP**.
3. Copy a template into your own project and fill it in.
4. Work through the interview questions topic by topic.
